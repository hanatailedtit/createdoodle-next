# 끄적끄적 브랜드 로고

접힌 모서리와 보라색 테두리가 있는 정사각형 메모지에 연필로 글을 쓰는 아이콘입니다.

- `memo-pencil.svg`: 편집 가능한 128 × 128 벡터 원본 (헤더, 모바일 드로어, 푸터, 404, SVG 파비콘).
- `memo-pencil.png`: 투명 배경의 512 × 512 PNG (Apple Touch Icon, PNG 파비콘 폴백, RSS 피드 이미지).
- `memo-pencil-preview.png`: 블로그 이름과 함께 배치한 미리보기 (Open Graph / 소셜 공유 대표 이미지).

메모지와 워드마크는 흰색·보라색 계열입니다. 연필 내부는 명암 없이 모두 흰색이며, 보라색 윤곽선으로 형태를 구분합니다.
