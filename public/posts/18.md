# CAN, 시리얼, 이더넷의 차이점과 임베디드 시스템 내 역할 총정리

CAN 통신, 시리얼 통신, 이더넷 통신은 임베디드 시스템에서 가장 핵심적이고 널리 쓰이는 3대 유선 통신 방식이다. 이 글은 이 세 가지 통신 방식에 대해 기술하였다.

# CAN 통신 (Controller Area Network)

- 1980년대 보쉬사가 자동차 내의 수많은 전자제어장치(ECU)들을 효율적으로 연결하기 위해 개발한 통신 방식
- 자동차나 공장 같은 극한의 환경 (진동, 전기적 노이즈 등)에서도 데이터 오류 없이 안정적으로 통신할 수 있도록 설계됨으로써 높은 신뢰성과 노이즈 내성을 가짐
- 중앙 통제 장치 없이 네트워크에 연결된 모든 노드(기기)가 평등하게 데이터를 보낼 수 있음. 메세지에 우선순위를 부여하여 충돌을 방지함 (멀티 마스터 (Multi-Master))
- 주요 용도는 자동차 내부 네트워크, 엘리베이터, 공장 자동화 기기, 로봇 제어 시스템에 사용됨

# 시리얼 통신 (Serial Communication)

- 데이터를 한 번에 1비트씩 순차적으로 전송하는 아주 오래되고 기본적인 통신 방식.
- 흔히 UART, RS-232, RS-422, RS-485 등의 규격으로 불림
- 구조가 매우 직관적이며 전선 가닥 수가 적어 하드웨어 구현 비용이 저렴하여 단순함과 경제성을 한번에 잡음
- 주요 용도는 마이크로컨트롤러(MCU)와 센서 간의 통신, PC와 구형 주변기기 연결, 전광판 제어, 간단한 산업용 모니터링 장비에 쓰임

# 이더넷 통신 (Ethernet)

- 우리가 흔히 사용하는 유선 랜(LAN) 혹은 인터넷 통신의 국제 표준 기술 (IEEE 802.3) 임
- 앞의 두 방식과 비교할 수 없을 정도로 압도적인 데이터 전송 속도를 보여주며, 메가비트(Mbps)를 넘어 기가비트 (Gbps), 테라비트 단위까지 발전하고 있음
- 전 세계 어디서나 사용하는 IP 기반 네트워크와 쉽게 연결할 수 있으며, 스위치나 라우터를 통해 수많은 기기를 무한히 확장하여 연결할 수 있기 때문에 뛰어난 확장성과 범용성을 가짐
- 주요 용도는 PC 및 서버 네트워크 인프라, 고화질 영상 스트리밍, 대용량 데이터 전송
- 최근에는 대용량 데이터 처리가 필요한 자율주행차 내부 통신용 Automotive Ethernet으로도 쓰이고 있음

## 이더넷(Ethernet)과 인터넷(Internet)의 차이

- 이더넷(Ethernet)과 인터넷(Internet)은 서로 밀접하게 연결되어 있지만, 완전히 다른 개념
- 이더넷은 우리 동네의 도로망이고, 인터넷은 전 세계 동네 도로들을 모두 이어놓은 글로벌 고속도로 시스템

### 이더넷 (Ethernet) : 물리적 근거리 망

이더넷은 집이나 사무실, 공장 같은 한정된 공간(LAN, 근거리 통신망) 안에서 컴퓨터나 장비들을 서로 선(랜선)으로 연결하기 위한 기술 표준이다.

- 흔히 데스크톱이나 노트북에 꽂는 굵은 랜선(RJ45 케이블)과 불빛이 깜빡이는 스위치 허브 장비가 바로 이더넷 기술의 실체
- 인터넷이 끊겨도 작동: 만약 통신사에 장애가 생겨서 외부 인터넷이 끊기더라도, 회사 내부의 이더넷 망은 살아있음. 인터넷이 안 돼도 사내 메신저를 쓰거나, 사내 프린터로 인쇄를 하고, 공장 컨베이어 벨트를 제어할 수 있는 이유가 바로 기기들이 '이더넷'으로 묶여 있기 때문
- 식별자: 이더넷 안에서는 기기들을 구분할 때 IP 주소가 아니라, 랜카드에 아예 새겨져 나오는 하드웨어 고유 번호인 MAC 주소를 사용

### 인터넷 (Internet): 전 세계 이더넷을 연결한 거대한 가상 공간

인터넷(Inter-Network)은 글자 그대로 수많은 네트워크(이더넷 망)들을 서로(Inter) 연결해 놓은 전 세계적인 거대 통신망(WAN)이다.

- 우리 집 이더넷 망, 회사 서버실의 이더넷 망, 미국 구글 본사의 이더넷 망을 거대한 해저 케이블과 '라우터'라는 장비를 통해 하나로 묶어낸 결과물로서 네트워크의 네트워크 임
- 인터넷은 물리적인 선의 종류보다는, 전 세계 어디서나 똑같은 방식으로 데이터를 주고받기 위한 전 세계 공통어인 **TCP/IP 프로토콜**을 핵심으로 소프트웨어적 통신 규칙을 정의함
- 전 세계 수십억 대의 기기가 서로를 찾아가기 위해, 우리가 잘 아는 IP 주소(예: `192.168.0.1`)라는 가상의 우편번호를 부여받아 식별자로 통신

| **구분**        | **이더넷 (Ethernet)**                     | **인터넷 (Internet)**                  |
| --------------- | ----------------------------------------- | -------------------------------------- |
| **비유하자면?** | 우리 회사 내부의 **내선 전화망**          | 전 세계로 걸 수 있는 **국제 전화망**   |
| **연결 범위**   | 집, 사무실, 공장 내부 (근거리, LAN)       | 전 세계 (원거리, WAN)                  |
| **핵심 역할**   | 물리적인 케이블과 장비로 기기를 직접 연결 | 서로 다른 네트워크들을 논리적으로 연결 |
| **데이터 주소** | **MAC 주소** (하드웨어 고유 번호)         | **IP 주소** (논리적 인터넷 주소)       |
| **필요 장비**   | 랜 케이블, 스위치 (허브)                  | 라우터 (공유기), 모뎀                  |

우리는 컴퓨터를 이더넷(랜선)에 연결하고, 그 이더넷 망이 공유기와 라우터를 거쳐 바깥세상으로 나가 **인터넷**과 연결되는 구조이다. 따라서 이더넷은 인터넷을 하기 위한 가장 대중적인 수단(도로) 중 하나일 뿐, 인터넷 그 자체는 아니다. (Wi-Fi나 5G 같은 무선 통신도 이더넷을 대체하는 또 다른 접속 수단이다.)

# 세 가지 통신 비교표

| **구분**         | **CAN 통신**                                                                 | **시리얼 통신**                                             | **이더넷 통신**                                                      |
| ---------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------------------- |
| **통신 속도**    | 중간 (최대 약 1Mbps)                                                         | 느림 (보통 수십~수백 kbps)                                  | 매우 빠름 (10Mbps ~ 100Gbps 이상)                                    |
| **통신 거리**    | 최대 1km (단, 거리가 길어지면 속도 저하)                                     | 규격에 따라 다름 (RS-485의 경우 최대 1.2km)                 | 케이블당 100m (스위치/리피터로 무한 연장 가능)                       |
| **가장 큰 장점** | 전기적 노이즈에 강함, 메시지 우선순위 처리                                   | 구현이 매우 쉽고 단가가 저렴함                              | 대용량 데이터 고속 전송, 무한한 확장성                               |
| **비유하자면?**  | **사내 방송망:** "화재 발생! 대피하라!" (중요한 짧은 메시지를 확실하게 전달) | **종이컵 전화기:** 두 지점 간에 조곤조곤 대화를 나누는 용도 | **고속도로망:** 수많은 택배 차(데이터)가 엄청난 속도로 오가는 물류망 |

# 임베디드 분야에서 세가지 통신의 역할

## 시리얼 통신 (UART, I2C, SPI): 메인 보드 내부의 신경망

임베디드 시스템의 가장 기본이자 근간이 되는 통신이다.

- MCU와 주변 기기 연결: 칩(Microcontroller)과 칩, 혹은 메인 보드와 단순 온도/습도 센서 등을 연결할 때 가장 먼저, 그리고 가장 많이 고려되는 통신
- 특징: 주로 수 센티미터(cm) 이내의 같은 PCB(초록색 회로 기판) 위에서 데이터를 주고받음. 구조가 단순하여 자원을 거의 차지하지 않음
- 실제 적용
  - 장비 내부의 온도를 측정하는 단순 칩 센서 데이터 읽기
  - 개발자가 PC를 연결해 장비의 부팅 상태나 에러 로그(텍스트)를 확인하는 디버깅 포트 용도

## CAN 통신: 외부 장치들을 제어하는 튼튼한 근육망

단순한 1:1 연결을 넘어, 여러 기기가 험악한 환경에서 신뢰성 있게 통신해야 할 때 쓰이는 임베디드의 핵심이다.

- 역할: 메인 보드(두뇌)의 좁은 범위를 벗어나, 장비 외부에 달려 있는 여러 모터나 센서들을 튼튼하게 묶어 제어
- 특징: 거리가 수 미터(m)에서 수십 미터로 길어지고, 기계가 돌아가는 시끄럽고 거친 환경(전기적 노이즈)에서도 데이터가 깨지지 않도록 보호
- 실제 적용
  - 컨베이어 벨트를 돌리는 하위 모터들에 속도 조절 명령 하달
  - 멀리 떨어져 있는 여러 구역의 센서(연기, 압력 등) 신호 취합 및 모니터링

## 이더넷 (Ethernet): 바깥 세상과 소통하는 초고속 외부망

과거에는 덩치 큰 PC나 서버의 전유물이었지만, 하드웨어 성능이 발전하면서 이제는 임베디드 통신의 대세로 자리 잡게 되었다.

- IoT와 스마트 팩토리: 임베디드 기기들이 점점 똑똑해지고 다루는 데이터(영상, 비전 검사 이미지 등)가 커지면서, 이를 감당하고 외부 클라우드 망에 연결하기 위해 소형 임베디드 보드에도 이더넷 통신 칩이 필수적으로 들어가는 추세
- 역할: 하위 센서(시리얼)와 모터(CAN)에서 수집한 모든 상황을 종합하여, 공장의 중앙 관제 서버나 외부 클라우드로 대용량 데이터를 쏘아 올림
- 특징: 데이터를 처리하는 양과 속도가 앞의 두 방식과 비교할 수 없을 정도로 높으며, 인터넷망(TCP/IP)과 바로 연결될 수 있는 범용성을 가짐
- 실제 적용
  - 수집된 전체 시스템 데이터를 중앙 관리 서버(MES)의 DB로 실시간 전송.
  - 비전 카메라가 찍은 불량품 검사 고화질 이미지를 관제실로 스트리밍.

| **구분**        | **통신 범위**                | **비유**                | **핵심 역할 및 주요 취급 데이터**                                |
| --------------- | ---------------------------- | ----------------------- | ---------------------------------------------------------------- |
| **시리얼 통신** | **보드 내부** (수 cm 이내)   | 뇌와 바로 옆 감각 기관  | 칩 상태 확인, 단순 센서 값 읽기, 개발자용 텍스트 로그 출력       |
| **CAN 통신**    | **장비 간 연결** (수~수십 m) | 뇌와 외부 팔다리(근육)  | 노이즈가 심한 환경에서의 모터 제어 명령, 다수의 외부 센서망 구축 |
| **이더넷 통신** | **네트워크 망** (무한 확장)  | 외부 기관과의 소통 채널 | 중앙 서버와의 통신, 고화질 영상 전송, 대규모 트래픽 처리         |
